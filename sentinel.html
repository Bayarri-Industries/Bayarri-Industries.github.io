In Development

Sentinel is Bayarri Industries' first deployed product — a real-time AI threat detection system that processes live sensor input and identifies threats the moment they appear. Persons, vehicles, unknown objects — Sentinel classifies them, flags them, and hands the decision off at machine speed.

It is the first real-world application of Orion. The same AI that reasons, learns, and adapts behind the scenes is the engine that powers every classification Sentinel makes.

What It Does

Sentinel takes live input from cameras or sensors, runs it through a pretrained object detection layer, and feeds results into Orion for contextual threat classification. It doesn't just detect — it interprets. The difference between a civilian vehicle and a threat vehicle. Between an unknown contact and a known one. That gap is where Sentinel operates.

The system is designed to run at the edge — on hardware available in the field, without cloud dependency. If the network goes down, Sentinel keeps running.

The First Product

Sentinel exists because the best way to prove a system works is to build something real with it. Every line of Sentinel is a proof of concept for the broader Bayarri ecosystem — that Orion can power real detection, in real time, on real hardware. What starts as a prototype becomes the baseline for everything that follows.

Where It's Going

The current prototype handles visual threat detection. Future iterations integrate Specter's radar data, giving Sentinel the ability to classify threats beyond visual range — targets that cameras can't see and conventional radar can't identify. When Specter and Sentinel are fully integrated through Orion, the result is a complete kill-chain-aware detection system. That's the target.
